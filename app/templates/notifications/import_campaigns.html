Importar Campañas de Notificación

{% include '_flash_messages.html' %}
Información sobre la importación:
  • El archivo debe ser un JSON válido exportado desde este sistema.
  • Las campañas se identifican por su nombre_campana.
  • Si una campaña ya existe y no marca la opción de sobrescribir, será omitida.
  • Se mostrará un resumen de las campañas importadas, actualizadas y omitidas.
Archivo de Campañas
Seleccione el archivo JSON con las campañas de notificación a importar.
Si está marcado, las campañas existentes serán actualizadas con los datos del archivo. Si no está marcado, las campañas existentes serán omitidas.
Volver
Formato esperado del archivo JSON

El archivo debe tener la siguiente estructura:

{
  "export_metadata": {
    "export_date": "2025-08-13T10:30:00",
    "total_campaigns": 2,
    "version": "1.0"
  },
  "campaigns": [
    {
      "nombre_campana": "Notificación Acta Constitución",
      "asunto_email": "Acta de Constitución - Concurso <<expediente>>",
      "cuerpo_email_html": "<p>Estimado/a <<nombre_destinatario>>,</p>...",
      "destinatarios_json": {
        "tribunal_destinatarios": [
          {"rol": "Presidente", "claustro": "Docente"},
          {"rol": "Titular", "claustro": "Docente"}
        ],
        "otros_roles_destinatarios": ["postulantes"],
        "emails_estaticos": ["admin@universidad.edu"]
      },
      "documentos_adjuntos_config": [
        {"document_type_key": "ACTA_CONSTITUCION_TRIBUNAL_REGULAR", "version": "FIRMADO"}
      ],
      "adjuntos_personalizados": ["1abc123def456"],
      "estado_al_enviar": "NOTIFICADO",
      "subestado_al_enviar": "Acta de constitución notificada"
    }
  ]
}
Campos importantes
  • destinatarios_json: Configuración de destinatarios con roles de tribunal, otros roles y emails estáticos
  • documentos_adjuntos_config: Array de configuraciones de documentos a adjuntar con su tipo y versión
  • adjuntos_personalizados: Array de IDs de Google Drive para adjuntar archivos personalizados
  • estado_al_enviar: Estado que se aplicará al concurso cuando se envíe la campaña
  • subestado_al_enviar: Subestado que se agregará al concurso cuando se envíe la campaña
